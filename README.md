Данный проект - это учебное приложение на Python для управления банковскими операциями.

## 1. Модуль маскирование банковских реквизитов
Модуль `masks.py` содержит набор функций для маскирования номеров банковских карт и счетов.

### Функции модуля

- `get_mask_card_number`

Маскирует номер банковской карты, оставляя видимыми первые 4 цифры, две цифры из середины (позиции 4-6), последние 4 цифры

Формат вывода: `XXXX XX** **** XXXX`

- `get_mask_account` 

Маскирует номер банковского счета, оставляя видимыми только последние 4 цифры.

Формат вывода: `**XXXX` (где XXXX - последние 4 цифры)

## 2. Модуль обработки банковских данных
Модуль `widget.py` содержит набор функций для маскировки конфиденциальных данных и форматирования дат.

### Функции модуля

- `mask_account_card`

Определяет тип реквизита (карта/счёт) и возвращает замаскированную версию:

Для карт: `"Visa Platinum 1234 56** **** 3456"`

Для счетов: `"Счет **7890"`

- `get_date`

Преобразует дату из формата `"YYYY-MM-DD"` в `"DD.MM.YYYY"`

## 3. Модуль обработки банковских операций

- `sort_by_date`

## 4. Модуль генераторов банковских данных

Модуль `generators.py` содержит набор функций для работы с банковскими транзакциями и генерации данных.

### Функции модуля

- `filter_by_currency` 

   Фильтрует список транзакций по коду валюты ("USD", "RUB" и т.д.)

**Пример использования:**
```python
transactions = [
    {"id": 939719570,"operationAmount": {"currency": {"code": "USD"}}},
    {"id": 142264268, "operationAmount": {"currency": {"code": "RUB"}}}
]


usd_transactions = list(filter_by_currency(transactions, "USD"))
# Вернет список с одной транзакцией (id=939719570)
```

- `transaction_descriptions` 

   Возвращает итератор описаний транзакций
```python
transactions = [
    {"description": "Перевод организации"},
    {"description": "Перевод с карты на карту"}
]

for desc in transaction_descriptions(transactions):
    print(desc)
# Выведет:
# Перевод организации
# Перевод с карты на карту
```
- `card_number_generator`  

   Генерирует номера карт в формате "XXXX XXXX XXXX XXXX" в заданном диапазоне
```python
cards = card_number_generator(1, 3)
for card in cards:
    print(card)
# Выведет:
# 0000 0000 0000 0001
# 0000 0000 0000 0002  
# 0000 0000 0000 0003
```

## 5. Модуль декоратор логирования `@log`

Автоматическое логирование вызовов функций с записью в файл или выводом в консоль.

### Использование

```python
@log()  # Вывод в консоль
def my_func(x):
    return x * 2

@log("operations.log")  # Запись в файл
def add(a, b):
    return a + b
```
### Примеры вывода
Успешный вызов:
```
add ok
```
Ошибка:
```
divide error: ZeroDivisionError. Inputs: (1, 0), {}
```
