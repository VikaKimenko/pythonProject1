# Учебный проект банковского приложения на языке Python

## Описание:

Данный проект - это учебное приложение на Python для управления банковскими операциями.

## Установка:

1. Клонируйте репозиторий:
```
dit clone https://github.com/VikaKimenko/pythonProject1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Тестирование проекта
